# front-v2 — ملف التسليم (ابدأ من هنا)

> اقرأ الملف ده الأول في أي شات جديد أو أي أداة AI. فيه كل اللي اتفقنا عليه، وإحنا وصلنا فين، وإيه اللي جاي.
> آخر تحديث: 2026-11-11 · الفرع: `v4`

---

## 1) الفكرة في سطرين

- بنبني **فرونت جديد كامل** في فولدر `front-v2/` جنب الفرونت القديم `front/`. القديم **متجمّد**: مفيش ميزات جديدة فيه، وبيفضل مرجع لحد ما نمسحه.
- **الباك (`back/`) زي ما هو**. الـ API والتحقق والبيانات واحدة، وبنعدّل في الباك واحنا ماشيين لما نحتاج.
- مفيش رفع على السيرفر غير لما الجديد يخلص كله. ساعتها نمسح `front/` ونغيّر اسم `front-v2` لـ `front`.

## 2) القرارات (المالك وافق عليها)

| الموضوع | القرار |
|---|---|
| اسم المنصة | **«مكسب»** مؤقتًا. متعرّف في مكان واحد: `front-v2/src/config/brand.ts` (+ العلامة في `components/brand/logo.tsx`) |
| الألوان | **تحت الاختيار.** المالك رفض أول ألوان (كحلي/برتقالي/أصفر) لأنها شكلها «ألوان AI». فيه 3 هويات كاملة في `front-v2/src/app/globals.css`: **«حبر»** (جرافيت + برتقالي غامق، الافتراضية دلوقتي)، **«تمر»** (بني تمر + طين + زعفران)، **«نيل»** (أخضر النيل + كهرمان). بتتقارن في أول قسم في صفحة المكونات، وزرار «جرّبها على الصفحة» بيطبّقها على الداشبورد كله (بتتحفظ في المتصفح). **لما المالك يختار:** الهوية المختارة تبقى `:root`، والباقي يتمسح، ويتمسح `config/palettes.ts` و`features/showcase/palette-picker.tsx` وسكريبت `PALETTE_BOOT_SCRIPT` من `app/layout.tsx` |
| الوضع الليلي | فاتح بس دلوقتي، والألوان متعرّفة بطريقة تخلّي الليلي يتضاف بعدين ببلوك واحد |
| اللوجو | علامة مؤقتة SVG مرسومة في الكود (شنطة برتقالي). لما يوصل ملف SVG نهائي يتبدّل في `logo.tsx` |
| الرسوم البيانية | **Recharts** (مكتبة مفتوحة المصدر، مش خدمة خارجية) ملفوفة في `components/data/charts.tsx` |
| أساس المنصة | **المتجر**. صفحات الهبوط أداة تسويق تحت قسم «التسويق» |
| المخزون | جوّه تفاصيل المنتج، مفيش شاشة مخزون لوحدها |
| ملف الرسائل | كل نص عربي في `messages/ar/<قسم>.ts`، و`messages/ar.ts` بيجمّعهم وهو المدخل الوحيد (`import { ar } from "@/messages/ar"`) |
| طريقة الشغل | **جزء جزء**. نخلّص جزء كامل ونراجعه، وبعدين اللي بعده. المالك هيشرح كل جزء (مثلًا الثيمات) قبل ما نبدأه |
| الثيمات | ثيمات المتاجر واللاندنج **هتتبني من جديد** مع المالك، واحدة ورا التانية، لما نوصل لجزءها |
| المحرر (Builder) | هيتحسّن بشكل كبير، لما نوصل لجزءه |
| داشبورد الأدمن | هيتعاد كله |
| git | فروع v3 اتدمجت في `main` (على الجهاز بس). الشغل الجديد على فرع **`v4`**. مفيش رفع |

## 4) تشغيل وأوامر

```bash
cd front-v2
pnpm install
pnpm dev            # http://localhost:3200/dashboard/components
pnpm lint && pnpm typecheck && pnpm test && pnpm build
```

- الفرونت القديم يفضل على `:3000` والباك على `:8010` (`bash tools/start-dev.sh`).
- `front-v2` لسه مش بيكلّم الباك. الربط بيبدأ في F2.

## 5) تنظيم الكود في front-v2

```
front-v2/src/
  app/                    الصفحات (routes). رفيعة: بتجمّع مكونات بس
    (dashboard)/layout.tsx   الإطار (AppShell)
    (dashboard)/dashboard/components/   صفحة المكونات
  config/
    brand.ts              اسم المنصة
    navigation.ts         القايمة الجانبية + حالة كل صفحة (ready/soon)
  components/
    ui/                   الأساسيات: button, badge, input, field, choice (select/checkbox/switch/radio), panel, tabs, overlay (dialog/drawer/menu/popover/tooltip), feedback (alert/empty/error/locked/skeleton/toast)
    forms/                form-layout (FormLayout/FormSection/SaveBar/useUnsavedWarning) + inputs (money, phone, quantity, color, file, media, markdown, multi-select, dates)
    data/                 data-table (+ FilterBar, Pagination), stat-card (+ Meter), charts, details (EntityCell, DescriptionList, Timeline, CopyField, Price, Checklist, Steps), sortable-list
    layout/               app-shell, sidebar, command-palette (Ctrl+K), page-header (+ Breadcrumbs)
    domain/               حاجات خاصة بالمنصة (حالات الطلب والفاتورة)
    brand/                اللوجو
  features/<قسم>/         شاشات كل قسم (مكوناتها + بياناتها). دلوقتي: showcase بس
  lib/                    format (أرقام/فلوس/تواريخ/موبايل)، use-url-state، utils
  messages/ar.ts + ar/*   كل النصوص العربي
```

**قواعد ثابتة:**
- **الألوان** من المتغيرات بس (`bg-surface`, `text-ink-2`, `bg-brand-soft`...). مفيش لون مكتوب في أي مكوّن، حتى اللوجو بيقرا `--logo-1/2/3`.
- **الزرار الأساسي كحلي** (`variant="primary"`)، زرار واحد لكل منطقة. البرتقالي (`brand`) للتمييز النادر. الأصفر للتنبيه بس.
- **الأرقام** بالإنجليزي (0-9) وبعرض ثابت (`tabular`). الأسعار بـ `formatMoney`، والتواريخ بتوقيت القاهرة بـ `formatDateTime`.
- **RTL**: classes منطقية بس (`ms/me/ps/pe/start/end`). حقول الأرقام والفلوس والموبايل `ltr`.
- **كل نص عربي** في `messages/ar/*`. ممنوع نص عربي جوّه مكوّن (إلا بيانات العرض في `features/showcase/fixtures.ts`).
- **4 حالات لكل شاشة**: تحميل (Skeleton)، فاضي (EmptyState)، خطأ (ErrorState + إعادة)، إشعار (toast).
- **الفورم**: react-hook-form + zod، وأخطاء السيرفر بتتحط على الحقل نفسه.
- **الجداول**: `DataTable`، وحالة البحث والفلاتر والترتيب والصفحة في الرابط (`useUrlState`).
- **مكوّن جديد؟** يتضاف في صفحة المكونات الأول بكل حالاته، وبعدين يتستخدم في الشاشات.
- **الحالات القياسية للطلب** بتيجي من الباك (`App\Enums\OrderStatus`): new, confirmed, delivered, returned, damaged, fake, cancelled.

## 6) قواعد المشروع اللي لسه سارية (من CLAUDE.md)
- الـ tenancy في الباك (BelongsToTenant، TenantExists/TenantUnique، cross-tenant → 404).
- كل endpoint جديد ليه اختبارات Feature: نجاح، تحقق، 401، عزل بين المتاجر.
- الفلوس `decimal(12,2)` في الداتابيز و cents في الكود، و`PriceCalculator` هو المرجع الوحيد للأسعار.
- مفيش خدمات خارجية من غير موافقة المالك. لو اتوافق عليها: تتسجّل في DECISIONS.md، وتبقى ورا interface، ومفاتيحها في `.env`.
- المالك عايز: Eloquent مش SQL خام، وسرعة وأمان، وتحديثات قصيرة بالمصري، و**الوقوف بعد كل جزء للمراجعة**.

## 7) «المحرّك» اللي هيتنقل من front/ (في F2 وما بعده، ملف ملف ومعاه اختباراته)

| من `front/src` | لزومه |
|---|---|
| `lib/api/*` (client, server, errors) + `app/api/bff/*` + `app/api/auth/*` | الاتصال بالباك وتسجيل الدخول بالكوكيز |
| `proxy.ts` + `lib/host/*` | توجيه الدومينات (app / المنصة / متاجر العملاء) |
| `app/api/revalidate` + `lib/public/revalidate.ts` | تحديث الكاش لما التاجر يعدّل |
| `lib/public/*` (api, store, store-route, seo, host, visitor) + `app/api/public/*` | واجهة المتجر وصفحات الهبوط |
| `lib/price/*`, `lib/store/*` (cart, quote, events) | الأسعار والعروض والسلة |
| `lib/tracking/*` | البيكسلات وتتبّع الزيارات |
| `lib/links.ts`, `lib/format/phone.ts`, `lib/governorates.ts`, `lib/dates.ts` | فلترة الروابط (حماية)، والموبايل، والمحافظات، والتواريخ |

**مهم:** شكل محتوى الصفحات المتخزن في قاعدة البيانات (`draft_content` / `published_content`: `{version, sections: [{id, type, variant, visible, props}]}`) بيتحقق منه الباك في `back/app/Services/PageContentSanitizer.php`. القواعد: المفاتيح اللي آخرها `_media_id` / `_media_ids` لازم صور المتجر نفسه، واللي آخرها `_url` لازم روابط آمنة، وأنواع الأقسام المسموحة في `back/config/landing.php`. أي محرر أو ثيم جديد يا إما يحافظ على الشكل ده، يا إما يغيّره في الباك ومعاه migration. القرار ده بيتاخد مع المالك أول جزء الثيمات/المحرر.
